# Tennis Scout AI 🎾
A machine learning-powered discovery engine for finding tennis players based on playstyle archetypes.

## Features (Planned)
* **Archetype Clustering:** Using K-Means to group players (Grinders, Net-Rushers, etc.).
* **Similarity Search:** Finding "Stylistic Twins" using Cosine Similarity.
* **Mobile First:** Built with a FastAPI backend and a SwiftUI frontend.

## Tech Stack
* **ML:** Python, Scikit-Learn, Pandas.
* **API:** FastAPI.
* **App:** Swift 6 / SwiftUI.# tennis-scout-ai
